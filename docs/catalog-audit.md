# 원문 카탈로그 전사 검토

> 이전 38앱 카탈로그의 보존 기록입니다. 현재 v1.1은 사용자 첨부의 정확한 37개 후보 URL을 별도 시드로 보존하며 전부 초기 점검 전입니다. 최신 수량·출처는 [SOURCE_MANIFEST](SOURCE_MANIFEST.md)를 따릅니다.

기준: 사용자가 제공한 「모두의 창업 2기 (2차 라운드) 클래식 악기 교육 전자도서관 개발 계획서 초안 (35종 웹앱 연동 통합본).md」, 작성 기준일 2026-10-14.

## 수량 불일치 처리

원문 제목 및 서술은 **35종**을 사용하지만, 2-2절 전수 매핑표에 실제로 나열된 **고유 웹앱 URL은 38개**다. 원문에 포함된 항목을 임의로 삭제하지 않고 38개를 모두 등록했다.

| 분류 | 고유 URL 수 |
| --- | ---: |
| 현악기 | 2 |
| 목관악기 | 9 |
| 금관악기 | 1 |
| 방과후·생활음악 | 14 |
| 공통 음악도구·창작 스튜디오 | 12 |
| 합계 | 38 |

AI 보조교사·전문가 감수관은 내부 기능이므로 외부 웹앱 수에 포함하지 않는다. 전자교재 Google Drive 링크, 통합 데이터셋 링크, 문서·폴더 링크는 웹앱 수에 포함하지 않는다. 원문의 오보에 예시 URL은 신규 등록 방법을 설명하기 위한 예시이며 보유 목록에 없으므로 실제 배포 앱으로 등록하지 않았다.

## 교재 14종

현악기 4종, 목관악기 5종, 금관악기 5종의 원문 Drive 링크를 모두 그대로 보존했다. 단원 수는 바이올린 10, 그 외 13종은 4로 반영했으며 부록은 별도 단원으로 세지 않았다. 제공된 Markdown은 교재 원본 자체가 아니므로 실제 교재 쪽수·단원 본문·전문가 감수 완료 여부를 새로 주장하지 않는다.

`reviewFocus`와 설명은 원문 2-5절의 검수 과제와 범위를 요약한다. 이 값은 검수 완료된 교수 지침이 아니라 **검토할 항목**이다. 모든 교재는 **전문 교사 검수 전 초안**으로 표시해야 한다.

## 데이터 형식과 분류

- `lib/catalog.ts`: `Instrument`, `WebApp`, `InstrumentFamily`, `AppCategory`, `AppType`, `CatalogCategory` 타입 및 `instruments`, `webapps`, `categories` 배열.
- `public/data/webapp_registry.json`: 38개 WebApp 객체를 담은 배열. URL 끝의 슬래시·해시·대소문자는 원문 그대로 유지.
- `category`: `strings`, `woodwinds`, `brass`, `folk`, `studio`.
- `appType`: `trainer`, `coach`, `tool`, `studio`. 원문 용도를 UI 필터로 정규화한 분류이며 실제 외부 앱의 기능 검증을 뜻하지 않는다.
- 검색 키워드·영문명·색상은 표시와 검색을 위한 메타데이터다. 핵심 지도 내용이나 검수 인증을 추가하지 않는다.

## 검증 범위

등록된 14개 교재 URL 및 38개 웹앱 URL이 제공 원문에 문자 그대로 존재하는지 검사했다. 웹앱 URL의 고유성 및 분류별 건수를 검사했다. 외부 사이트의 현재 가용성, iframe 허용 여부, 웹캠 권한·동작, postMessage 프로토콜 지원은 이 전사 검사 범위에 포함되지 않는다.
