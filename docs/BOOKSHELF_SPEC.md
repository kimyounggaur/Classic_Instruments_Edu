# 책장형 홈 계약

기준: 첨부 v1.1의 공통 책장 설계. 대상 프로젝트는 `classical-library`이며 국악 라이브러리를 별도로 만들었다고 표시하지 않는다.

## 화면과 책 카드

따뜻한 종이색·진한 남색 본문·CSS 나무 선반을 사용한다. 표지는 외부 사진/텍스처를 수집하지 않고 새로 만든 타이포그래피로 구성한다. 4악기 전환, 검색/필터/정렬, 책장·목록 전환, 이어읽기, 결과수, 합성/실제 자료 구분과 출처·권리 안내를 함께 제공한다. 목록 전환은 검색 상태를 바꾸지 않는다.

카드에는 제목·악기/체계·수준·판본·검수/권리·파일 종류·이어읽기·북마크를 표시한다. 책 열기 주 링크와 북마크 버튼을 중첩하지 않는다. 장식 책등은 `aria-hidden`으로 중복 낭독을 막는다. 합성 자료에는 카드·상세·출력마다 시연 표시가 필요하다.

## 자산과 읽기

- 기존 자산 파일의 존재와 공개 사용 권리를 분리한다. 권리 미확인 실제 PDF·SVG·표지는 공개 경로와 클라이언트 번들에서 제외한다.
- 이번 기본 데모는 새로 작성한 구조화 단원이다. PDF 파일이 없거나 사용 권리가 없으면 ‘PDF 준비 중’과 구조화 단원 보기를 안내한다. 가짜 다운로드·빈 새 탭·PPTX를 PDF로 표현하는 동작은 금지한다.
- `BookPresentation`은 자료·판본·표지 출처·표시 순서, `ReadingAsset`은 판본·형식·참조·실제 페이지 수·checksum·availability·권리를 가진다. 모르는 값은 `null`이다.
- `BookPosition`은 `projectId/resourceId/resourceVersionId/assetId`에 귀속된다. 구조화 자료는 unit ID로 복원한다. PDF 페이지 수는 실제 PDF를 검사했을 때만 기록한다.
- 삭제·보류·판본/자산 교체 시 이전 위치를 검증한다. 다른 판본의 같은 페이지로 자동 이식하지 않는다. 비교·명시적 적용으로만 변경한다.
- 단원 뷰어는 목차·본문·자료정보, 이전/다음·페이지 또는 단원 이동·확대·북마크·교안 담기·관련 앱·신고·로딩/오류 상태를 제공한다.
- PDF를 추후 연결할 경우 확대/페이지 입력/전후 이동/목차/오류/키보드/페이지 대체설명까지 구현하고, 변환본 전 페이지의 글꼴·악보·기호·누락을 시각 검사한다. 내장 PDF iframe만으로 완료를 선언하지 않는다.
- 열람·출력·다운로드는 독립 권리다. 명령 함수에서도 차단한다. 권리 제한 자료는 교안 출력에 메타데이터와 제한 안내만 남긴다.

## 앱 복귀와 화면 크기

단원의 app ID에 연결된 후보만 표시한다. 실제 내용/권리/체계 검증이 없는 앱은 점검 전 또는 비활성으로 표시한다. 카메라형/체계불일치 앱은 기본 비활성이다. 새 탭에 `noopener noreferrer`를 적용하고 원래 판본·단원·필터를 유지한다. 자동재생·권한요청·학습 완료 기록은 없다.

CSS grid/wrapping으로 배치하며 320/360px에서는 1~2열 중 실제 가독성을 우선한다. 768px 3~4열, 1440px 이상 5~7열은 가용폭에 따른 제안이다. 고정 열수나 배경 사진 위 절대 좌표를 강제하지 않는다. 44px 터치 목표, 가시 focus, 명암, 한국어 읽기 순서, 200% 확대와 reduced-motion을 점검한다.

## 책장 수락 기준

| ID | 검증할 내용 | 적용/판정 방법 |
|---|---|---|
| B01 | 실제 PDF 없는 자료는 PDF 완료로 표시하지 않음 | 기본 구조화 데모와 PDF 준비 중 분기 |
| B02 | 합성 책장과 승인 실자료 통계 분리 | 합성 8/실제 승인 0을 별도 집계 |
| B03 | 책 열기가 정확한 resource/version/asset을 선택 | 라우트·repository FK 검사 |
| B04 | 읽던 위치 새로고침·외부 이동 후 복원 | 구조화 unit 복원; 실제 PDF 페이지 복원은 PDF 연결 전 미적용 |
| B05 | 구판 보류·교체 경고, 자동 위치 이식 없음 | 보류와 새판본 명시 적용 시나리오 |
| B06 | 필터·정렬·목록 전환·뒤로가기 상태 유지 | query와 history 검사 |
| B07 | 권리 없는 자산 열기·출력·다운로드 차단 | UI 및 명령 함수 검사 |
| B08 | 320/360/768/1440/1920px·200%·키보드 | 자동 크기 검사와 수동 시각 확인을 구분 |
| B09 | 없는 표지는 타이포그래피 대체 | 외부 이미지 수집 없음 |
| B10 | 미점검 앱/영상 안내, 자동재생·권한요청 없음 | 후보 상태·외부 링크 계약 검사 |
| B11 | 프로젝트별 책/파일/저장 위치 분리 | `classical-library` namespace, 다른 프로젝트 데이터 거부 |
| B12 | 실제 PDF 사용 시 전 페이지 시각 검사 기록 | 권리 미확인 PDF는 사용하지 않으며 검사가 끝난 것으로 간주하지 않음 |

이 표는 수락 기준이다. 실제 실행 결과와 미실행 범위는 `TEST_REPORT.md`를 따른다.
