# 자산 권리와 제공 경계

조사일: 2026-10-15. 파일 존재와 권리 허락은 별개다. 이번 조사에서 기존 교재의 권리자·라이선스·열람/인쇄/재배포 허락 증거를 확인하지 못했다. 따라서 실제 자료의 권리는 `unknown`이며 현재 앱이 원문 파일을 제공하지 않는다.

## 실제 보유 파일

## 권리 데이터 처리

실제 교재에 대한 rights holder/license/evidenceRef/checkedAt/checkedBy는 미확인이다. 열람·인쇄·다운로드·재배포를 자동 허용하지 않는다. PDF 파일이 있으나 제공 권리가 없는 상태를 ‘공개 가능한 PDF 준비 완료’로 표시하지 않는다. 데모 서고는 타이포그래피 표지와 구조화 단원이며 실제 악기 교재의 대체본 또는 전문 승인본이 아니다.

후속 실제 자산 연결은 해당 resourceVersion의 권리 기록과 공개 판정, fileRef/checksum/pageCount 실측, 변환 시 전 페이지 시각검사를 함께 요구한다. 열람 허락이 인쇄/다운로드 허락을 대신하지 않는다. 앱의 권리별 명령 차단은 클라이언트 mock 시연이며 실제 비공개 파일 배포에는 서버 권한과 비공개 저장소가 필요하다.

## 외부 앱과 이미지

37 앱 URL은 연결 후보 메타데이터다. 앱 코드·이미지·교재를 복제하지 않으며 자동 fetch·iframe·CORS 우회·카메라/마이크 실행을 하지 않는다. 권리/내용/체계/실행 점검이 없는 링크는 검증 완료로 표시하지 않는다. 외부 사진·표지·텍스처·음원·폰트 파일을 자동 수집하지 않았다.
