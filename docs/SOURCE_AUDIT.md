# 교재 원본 및 데이터 확인

확인일: 2026-10-14. 개발 기준은 사용자가 첨부한 「클래식 악기 교육 전자도서관 개발 계획서 초안 (35종 웹앱 연동 통합본)」이다.

## 실제 가져온 자료

- 계획서에 연결된 Google Drive 교재 폴더의 PPTX 14개를 읽기 전용으로 다운로드했다. 원격 파일·공유 설정은 변경하지 않았다.
- PPTX의 실제 슬라이드 순서를 기준으로 631쪽의 텍스트와 목차를 추출했다. 교재 내용을 요약문으로 대체하지 않았다.
- 원본 레이아웃을 PDF로 변환하고, 각 페이지를 SVG로 제공한다. SVG에는 PDF에 사용된 글꼴을 추출·복원한 페이지별 서브셋 웹폰트와 이미지가 내장된다. 본문은 확대 가능한 벡터 텍스트이며 원본 래스터 삽화의 해상도는 원본의 한계를 따른다.
- 파일별 PDF, 표지 미리보기, 페이지별 SVG, 원문 텍스트는 `public/textbooks/`와 `public/data/textbooks.json`에 있다. 원본 PPTX의 Drive 링크를 함께 기록한다.
- 별도 원본 `verified_textbook.json`은 4개 악기·19개 항목이다. `verifiedContent`, `fingeringSpec`, `cautionNotes`, 단원·쪽수·출처 링크가 있다.

## 확인된 상태

교재에는 전문 교사 검수 전이라는 안내와 AI 보조 삽화 안내가 있다. 지식 데이터셋 이름에 `verified`가 있더라도 감수자·서명·감수일·승인 증빙 필드는 없다. 따라서 가져온 교재와 지식 항목의 상태는 초안이며 감수 완료 인증이나 정확도 보증으로 표시하지 않는다.

계획서의 멀티앵글 전문가 촬영, 14인 공식 감수, ISBN, 현장 실증 지표, 기관 도입 확약서는 앞으로 확보할 외부 산출물이다. 이번에 읽은 자료에는 해당 증빙과 영상 원본이 없었다. 소프트웨어는 이 자료를 등록·연결할 수 있도록 구현하되 존재하는 것으로 꾸미지 않는다.

지식 데이터셋 플루트 출처의 Drive ID는 계획서의 플루트 파일과 다르다. 두 ID 모두 `플루트_최종통합교재_20261011.pptx`, 14,185,994바이트로 확인되었다. 원문 출처는 유지하며 교재 뷰어는 계획서 폴더에 있는 파일을 사용한다.

## 변환 점검 및 재생성

PDF 페이지 수와 PPTX 슬라이드 수를 전권 대조했다. 한국어 글꼴이 없는 초기 변환본은 사용하지 않고 Noto Sans KR를 설치한 뒤 전권을 재변환했다. 바이올린 자세 페이지, 플루트 운지 페이지, 바순 입문 페이지와 클라리넷 도식의 한국어 표시를 확인했고, 실제 Chromium의 `<img>` 안에서도 SVG 내장 글꼴 표시를 확인했다. 631쪽의 문자 매핑을 전수 검사했으며 바이올린 20쪽은 원본 PDF의 음악기호 ToUnicode 매핑이 불완전하여 해당 페이지만 원본 글리프 윤곽선을 유지했다. 모든 페이지 자산의 존재와 페이지 수를 대조했다.

`scripts/import_textbooks.py --source SOURCE_FOLDER`는 `SOURCE_FOLDER/textbooks_text.json`과 `SOURCE_FOLDER/rendered/*.pdf`에서 웹 자산을 만든다. 원본 폴더의 `double-bass`는 앱 ID `bass`로 매핑한다. `scripts/svg_fonts.py`는 PDF의 ToUnicode 매핑을 이용하여 원본 서브셋 글꼴의 유니코드 문자표를 복원한다. 필요한 Python 패키지는 PyMuPDF, Pillow, fontTools, lxml이다. PPTX를 PDF로 변환할 때는 한글 글꼴이 설치된 LibreOffice를 사용한다.

최초 가져오기용 원본 PPTX와 변환 중간 파일은 앱 공개 디렉터리에 포함하지 않았다. PPTX 텍스트는 원본 순서대로 추출한 읽기·검색용 텍스트이며, 줄바꿈·띄어쓰기는 원본 슬라이드 텍스트 개체에 따른다.
