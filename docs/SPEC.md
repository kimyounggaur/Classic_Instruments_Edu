# 개발판 사양

이 사양은 운영 서비스 사양이 아니다. 현재 브라우저 탭 안에서 교육 흐름을 검토하기 위한 합성 시연 사양이다.

## 제공 범위

- 14종 클래식 악기 교재, 631쪽의 변환 자산, 검색·책갈피·플립북 흐름
- 원문 URL과 38개 앱의 카탈로그 메타데이터
- 19개 미검수 원자료의 결정적 발췌 검색과 출처 페이지 이동
- 합성 승인 멀티앵글 시연, 거울·속도·A–B 구간 UI
- 익명 수업 미션·진행 현황 시연과 감수 의견의 탭 내 기록

## 제외 범위

- 전문가 감수 완료, 실제 전문가 영상, 자동 자세·운지 판정, 성적 산출
- 실계정 로그인, 학생 이름·연락처·식별자, 교실 간 공유, 서버 영속 저장
- 카메라·마이크 권한, 영상·음성 녹화, 외부 앱 iframe, 외부 생성형 AI 호출

## 표시 규칙

- 교재와 19개 원자료에는 `전문 교사 검수 전` 또는 `미검수 원자료`를 표시한다.
- 목표 24개와 합성 시연에는 전문가 검수·공식 승인과 구별되는 안내를 붙인다.
- 근거가 없는 질문은 답변하지 않고 원문 확인을 안내한다.
