# 앱 카탈로그 연결 범위

> 이전 구현의 보존 기록입니다. 현재 v1.1의 37앱 후보는 초기 점검 전·비활성이며 URL·체계·권한·수동 점검 증거 조건을 적용합니다. 최신 계약은 [DATA_CONTRACT](DATA_CONTRACT.md)를 따릅니다.

현재 개발판의 38개 웹앱 URL은 사용자가 제공한 카탈로그 원본을 식별하기 위한 메타데이터다. `components/AppFrame.tsx`는 URL의 호스트명과 교재 맥락만 보여주는 `합성 승인 시연`을 렌더링하며, 외부 앱을 iframe·새 창·메시지 브리지로 실행하지 않는다.

사용자가 추가하는 카드도 `demo.invalid` 식별자를 가진 탭 내 합성 카드로만 만든다. 외부 주소 입력, 카메라·마이크 권한 전달, 학생 정보 전송, 진도 메시지 수신은 구현하지 않는다.

향후 실제 연동은 별도 승인·보안 검토·운영 전환 범위가 정해진 뒤에만 검토한다. 이 문서는 그 미래 범위를 구현 완료로 주장하지 않는다.
