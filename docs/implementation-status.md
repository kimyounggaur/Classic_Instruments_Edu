# 설계 대비 구현 현황

> 이전 구현의 보존 기록입니다. 현재 v1.1의 수락 기준과 완료/미완료는 [SPEC](SPEC.md), [STATUS](STATUS.md), [TEST_REPORT](TEST_REPORT.md)를 따릅니다. 아래 항목은 이번 작업의 새 실행·승인 증거가 아닙니다.

기준 문서: 사용자가 첨부한 클래식 악기 교육 전자도서관 개발 계획서와 현재 작업공간의 구현이다. 이 문서는 운영 배포나 실제 수업 결과가 아니라 2026-10-14 mock-first 개발판에서 실제 코드와 검사로 확인한 범위만 기록한다.

## 비활성 범위

- 실계정 로그인, 플랫폼 사용자 헤더, 학생 식별정보, 서버 동기화와 D1 저장
- 카메라·마이크 권한, 영상·음성 녹화, 외부 앱 iframe, 외부 생성형 AI 호출
- 전문가 실연 영상, 자동 자세·운지 분석, 성적·성과 산출, 운영 배포

## 검증 기준

`STATUS.md`와 `TEST_REPORT.md`에 가장 최근 실행 결과를 기록한다. 해당 결과는 코드·데이터 경계·빌드의 검증이며, 음악 교육 내용의 전문가 감수나 현장 실증을 뜻하지 않는다.
