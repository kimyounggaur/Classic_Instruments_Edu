# 5분 로컬 시연

이 문서는 재현 순서다. 실행 성공 기록은 `TEST_REPORT.md`에서 확인한다. 실계정·실학생·전문가 승인 또는 37앱 정상 실행 시연이 아니다.

1. **0:00–0:40 · 책장** — README대로 로컬 서버를 실행해 `http://127.0.0.1:3000`을 연다. 시연 배너와 4악기, 합성 데모 책장과 실제 승인 0건을 확인한다. 바이올린/첼로/플루트/클라리넷을 차례로 선택하고 타이포그래피 책 표지를 본다.
2. **0:40–1:15 · 검색과 목록** — 검색에 `플룻`, 이어서 `  FLUTE  `를 입력한다. 필터·정렬을 바꾸고 책장/목록을 전환한다. URL에 상태가 남고 결과 0건에서는 초기화 방법이 있음을 본다. 실제자료 공개 보기는 0건이며 관리자 초안이 나타나지 않는다.
3. **1:15–2:00 · 책 열기와 이어읽기** — 합성 자료를 열어 출처·판본·검수/권리·PDF 준비 중/구조화 자료 구분을 확인한다. 다음 단원으로 이동, 확대, 북마크를 누르고 새로고침한다. 같은 판본·단원 복원을 본다. 실제 PDF가 연결되지 않았으므로 PDF 3쪽 복원 완료라고 설명하지 않는다.
4. **2:00–2:45 · 교안** — 단원을 수업안에 담아 수업 준비 화면을 연다. 40분 예시의 5+10+15+10 활동과 고정된 resource/version/unit을 확인한다. 제목/메모를 바꾸어 저장, 새로고침, 복제한다. 활동 시간을 줄여 불일치 안내를 본 뒤 원래 합계로 돌린다.
5. **2:45–3:20 · 연습과 복귀** — 현재 단원의 관련 앱과 연습실을 연다. 기본 후보는 점검 전·비활성이며 ‘열기’ 성공으로 연습 완료나 점수를 기록하지 않는다. 확인되지 않은 사이트를 실제 점검한 것처럼 활성화하지 않는다. 정적 대체자료로 돌아와 책·판본·단원·필터가 유지되는지 확인한다. 후속 실제 점검을 거친 후보가 있을 때만 새 탭 링크와 원래 화면 복귀를 시연한다.
6. **3:20–3:50 · 출력** — 교안 인쇄 미리보기를 연다. 메뉴/편집 버튼은 숨고 제목·활동·시간·출처/판본·시연 안내가 남는지 확인한다. 인쇄 불가 자산은 본문 대신 제한 안내/메타데이터만 남아야 한다. 프린터로 실제 출력할 필요는 없다.
7. **3:50–4:30 · 오류 신고** — 단원의 위치가 고정된 신고를 작성한다. 연락처·학생 이름을 넣지 않는다. 일반 의견은 검토 대기, 안전/핵심 음악 중대 신고는 보류되는 흐름을 확인한다. 보류 자료를 참조한 교안 경고와 북마크/직접 URL 제한을 본다.
8. **4:30–5:00 · 관리자** — 가상 역할을 바꾸고 19 미검수 메타데이터·24 제안 계획·37 앱 후보를 별도 집계로 본다. 관리자 전용 합성 fixture에서 검토→수정→재검수→승인 절차 시연과 권리 때문에 공개가 막히는 이유를 확인한다. 승인본 개정은 새 초안이며 기존 교안 판본은 자동 교체되지 않는다.

시연 후 초기화가 필요하면 하단의 데이터 초기화를 선택하고 확인한다. 취소 시 데이터는 유지된다. 초기화는 이 앱의 브라우저 저장만 대상으로 하며 보존 원본 파일을 삭제하지 않는다.

## 추가 확인

- 키보드 Tab/Shift+Tab/Enter/Escape로 책·북마크·목차·교안·대화상자를 이동한다. 대화상자 종료 후 호출 버튼으로 focus가 돌아오는지 본다.
- 320/360/768/1440/1920px, 200% 텍스트 확대에서 가로 넘침·버튼 잘림·인쇄를 확인한다.
- 저장 차단/손상 상태에서는 성공 메시지가 아닌 메모리 모드·복구 안내가 보이는지 확인한다.
- 외부 앱 실행·음악 정확성·실제 PDF 품질·완전한 접근성 인증은 이번 데모가 증명하지 않는다.
