# 인수와 후속 범위

기준: 첨부 v1.1 책장형 홈, 2026-10-15. 실행 방법은 루트 README, 단계별 상태와 실제 검사 결과는 STATUS/TEST_REPORT를 따른다. 이 문서에 기능을 나열한 사실을 검사 통과로 해석하지 않는다.

## 인수할 코드와 데이터

- 진입점/경로: `app/`, 새 UI: `components/prototype/`, 도메인·시드·Promise repository: `lib/prototype/`.
- 데이터: 원자료 19개는 본문 없는 미검수 메타데이터, 24개는 제안 모듈 계획, 37개는 점검 전 앱 후보다. 각각 별도 집합이다.
- 합성 책장 8자료/16단원/4교안, 관리자 예외 흐름 합성 4자료/8단원을 별도 표시한다. 실제 승인자료는 0개다.
- 저장은 이 브라우저의 localStorage이며 역할은 시연 전환이다. 스키마·복원·충돌·손상/차단·초기화 안내를 repository 경계에서 처리한다.
- 기존 컴포넌트·Worker/D1 코드와 구형 테스트는 보존한다. 기본 로컬 앱에서 계정·외부 DB를 사용하지 않는다. 이전 Sites 명령은 `*:sites`, 이전 테스트는 `test:legacy`로 분리한다.
- 기존 교재 PDF/SVG/표지/원문 JSON 총 663파일은 `retained-private/`에 보존한다. 현재 앱에서 제공하지 않으며 파일별 해시는 `RETAINED_ASSET_INVENTORY.csv`에 있다.

## 자리표시자와 의도된 제한

책 표지는 새 타이포그래피, 단원 본문은 중립 구조화 예시다. 실제 주법·운지·호흡·자세의 검증된 설명이 아니다. PDF는 기존 파일의 공개 권리가 확인되지 않아 연결하지 않는다. PDF 준비 중 안내·구조화 단원 읽기와 실제 PDF 엔진을 혼동하지 않는다.

37 앱은 후보 목록이며 초기에는 점검 전·비활성이다. URL 정책·체계·점검 증거를 갖춘 후보만 명령으로 활성화할 수 있다. 관리자에 증거를 입력할 수 있다는 기능은 실제 점검 증거를 대신하지 않는다. 기본 오프라인 데모는 외부 사이트 성공에 의존하지 않는다.

합성 검수자는 승인 절차 시연용 역할이다. 실제 전문가명·서명·승인 증빙·음악 정확성·학습효과·ISBN·기관 도입 실적은 생성하지 않았다. localStorage 이력은 실제 감사 증거가 아니며 사용자가 수정할 수 있다.

## 별도 확인이 필요한 항목

최종 TEST_REPORT에서 실행/실패/미실행을 구분해 인수한다. 자동 검사만으로 WCAG 전체 준수, 음악 교육 적합성, PDF 전 페이지 품질, 외부 앱 안전성/정확성, 운영 보안을 인증하지 않는다. 화면 크기·키보드·200% 확대·인쇄·focus 확인은 기록된 실제 범위만 인정한다.

## 후속 결정

1. 실제 교재를 제공하려면 권리자/라이선스/허락 범위와 전문가 검수 증거를 판본별로 확보한다. PDF 실측 페이지 수·체크섬과 전 페이지 시각검사 후 자산을 연결한다.
2. 앱별로 실행·모바일·악기체계·교육 내용·권한/개인정보 범위를 실제 점검하고 증거를 남긴다. 카메라형 앱은 별도 검토 전 비활성이다.
3. 여러 사용자에게 제공하려면 실제 인증·서버 권한·비공개 파일·영속 DB·감사·백업·보관/삭제·충돌 정책을 새로 설계한다. 프로토타입 역할 스위치를 운영 권한으로 사용하지 않는다.
4. 배포·SSO·학생 진도·카메라 분석·AI 답변·유료화는 별도 요청과 구현/검증이 필요한 후속 범위다. 현재 로컬 결과에는 포함되지 않는다.
