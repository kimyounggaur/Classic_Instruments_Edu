# 레슨 디자이너 · 클래식 악기 교육 전자도서관

첨부한 v1.1 책장형 홈 설계를 기준으로 만든 한국어 로컬 프로토타입입니다. 바이올린·첼로·플루트·표준 Bb 클라리넷의 책장→검색→단원→수업안→연습 자료→출력→오류 신고 흐름을 시연합니다.

실제 승인 교재는 **0개**입니다. 기본 서고의 8개 자료는 새로 만든 중립 합성 예시이며 음악 교육 내용이 검증된 교재가 아닙니다. 원자료 19개는 미검수 메타데이터, 24개는 모듈 기획 목표, 37개는 점검 전 외부 앱 후보로 각각 구분합니다.

## 로컬 실행

Node.js 24와 pnpm 11을 권장합니다. 이번 작업 환경은 Node `v24.14.0`, pnpm `11.25.0`입니다. 기존 pnpm lockfile을 사용합니다.

1. 이 폴더에서 터미널을 엽니다.
2. 처음 한 번 의존성을 설치합니다.

   ```powershell
   pnpm install --frozen-lockfile
   ```

3. 개발 서버를 실행합니다.

   ```powershell
   pnpm dev
   ```

4. [로컬 전자도서관](http://127.0.0.1:3000)을 엽니다. 종료하려면 터미널에서 `Ctrl+C`를 누릅니다.

Windows에서는 `start-library.cmd`를 더블클릭해 같은 개발 서버를 실행할 수 있습니다.

실계정·외부 DB·API 키·`.env` 설정 없이 합성 데모로 동작합니다. 인터넷은 최초 의존성 설치와 사용자가 직접 여는 외부 앱에만 필요합니다. 기본 앱은 외부 사이트의 실행 성공에 의존하지 않습니다.

## 검사와 프로덕션 실행

```powershell
pnpm lint
pnpm typecheck
pnpm test
pnpm build
pnpm start
```

`pnpm start`가 실행 중인 상태에서 **다른 터미널**로 `pnpm test:e2e`를 실행합니다. E2E는 고정된 Playwright CLI `0.1.22`와 Chrome을 사용하며, 최초 CLI 준비에는 인터넷이 필요합니다. 개발 서버와 production build는 같은 `.next` 경로를 사용하므로 동시에 실행하지 않습니다.

`test`는 Node 내장 테스트 러너로 새 도메인 계약을 검사합니다. `test:e2e`는 브라우저 수락 검사이며 실제 실행 환경·브라우저 의존성과 결과는 [테스트 보고서](docs/TEST_REPORT.md)를 따릅니다. production 실행은 `build` 성공 후 `start`를 사용하며 주소는 같습니다. 검사 명령이 존재한다는 사실과 통과 결과는 구분합니다.

기존 Vinext/Sites 명령은 `dev:sites`, `build:sites`, `start:sites`, 구형 검사 묶음은 `test:legacy`로 보존했습니다. 기본 실행에는 사용하지 않습니다. 기존 Worker/D1·인증 코드가 남아 있다는 사실은 이번 앱의 외부 DB 연결·실계정 지원·배포 완료를 의미하지 않습니다.

## 저장과 초기화

북마크·읽던 위치·교안·관리자 시연 변경은 현재 브라우저에만 저장합니다. 저장 키는 `lesson-designer-library:classical-library:v1`이며 `schemaVersion: 1`을 기록합니다. 다른 브라우저/PC와 공유하거나 서버에 백업하지 않습니다. 브라우저 데이터 삭제 시 사라질 수 있습니다.

화면의 저장 실패 안내에서 복원/저장 상태를 확인할 수 있습니다. 손상 JSON·저장 차단·용량 부족이면 원본 저장을 성공한 것처럼 표시하지 않고 임시 메모리 모드를 안내합니다. 이 모드의 변경은 새로고침하면 사라집니다. 다른 탭과 충돌하면 새로고침하거나 편집 내용을 복사한 뒤 다시 진행합니다.

하단의 데이터 초기화 버튼을 누르고 확인하면 이 앱의 브라우저 시연 데이터를 초기화합니다. 취소하면 유지됩니다. 로컬의 보존 교재 파일을 삭제하지 않습니다. 실제 학생 이름·학교 명단·연락처·음성/영상·비밀번호를 입력하지 마세요.

## 콘텐츠와 권리

실제 PDF·페이지 SVG·표지·원문 JSON은 권리 증거가 확인되지 않아 `retained-private/`에 로컬 보존하고 앱에서 제공하지 않습니다. 기본 데모는 타이포그래피 표지와 구조화 단원이며 PDF 다운로드를 가장하지 않습니다. 기존 파일 663개의 경로·해시는 [자산 인벤토리](docs/RETAINED_ASSET_INVENTORY.csv)에 있습니다.

가상 역할 전환은 인증이 아닙니다. 합성 ‘승인 흐름 시연’은 전문가 승인·권리 확인·학습효과 검증이 아닙니다. 앱 후보는 초기 점검 전·비활성이며, 단순 링크 열기를 연습 완료나 점수로 기록하지 않습니다. 카메라·마이크·위치 권한, 실제 학생 진도, 외부 AI, 공통 로그인·SSO, 자동 배포는 포함하지 않습니다.
